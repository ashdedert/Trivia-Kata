# Trivia Quiz Kata Submission

## Author
Ashlyn Dedert

## Kata Option
Option 1: Quiz

## Overview
A browser-based trivia quiz using the Open Trivia Database API.  
Users can select quiz options, answer multiple-choice questions, and see their final score.

## Features
- Fetches questions from Open Trivia API
- Category and difficulty selection
- Selectable question count (5 or 10)
- 15-second timer per question
- Score tracking with final percentage
- Basic API error handling
